# Benchmarking-Approximate-Nearest-Neighbour-Search

## Setup

    python3 -m venv .venv && source .venv/bin/activate
    pip install -r requirements.txt

## Data

Download the two ann-benchmarks files (not included in the submission):

    mkdir -p data/sift data/glove
    wget -P data/sift  http://ann-benchmarks.com/sift-128-euclidean.hdf5
    wget -P data/glove http://ann-benchmarks.com/glove-100-angular.hdf5

The Part 4 data is generated by `code/drift_data.py` with a fixed seed; nothing to download.

## Running

    bash run_all.sh            # full reproduction (all report numbers)
    bash run_all.sh --quick    # first 100K vectors, smaller grids, < 15 min on a laptop

The full run takes several hours on one thread; most of it is building the HNSW
indexes on the full datasets. `--quick` writes to `results_quick/` and never
overwrites the full results.


Every script uses one thread (`faiss.omp_set_num_threads(1)` plus
`OMP/OPENBLAS/MKL_NUM_THREADS=1`) and times queries one at a time, as the median of
3 runs on the last 5,000 queries. Settings are chosen on the first 5,000 queries.

## Outputs

| Path | Contents |
|---|---|
| `results/results.csv` | one row per benchmark run behind a number in the report (`part` column = 1–4) |
| `results/figures/` | Part 2 recall–QPS plots, Part 3 scaling plot, Part 4 drift plot |
| `results/tables/` | Markdown tables used in the report |
| `results/exact_*.csv`, `results/part{2,3,4}/` | raw per-experiment results |

## Code

| File | Purpose |
|---|---|
| `code/recall.py` | tie-aware recall@k on true distances; `true_distances` helper |
| `code/test_recall.py` | unit tests for recall (`python code/test_recall.py`) |
| `code/exact_baseline.py` | Part 1: exact search validation and single vs batch timing; data loading |
| `code/benchmark.py` | Parts 2–3: build/sweep any index on any dataset or subset |
| `code/report_part2.py`, `code/report_part3.py` | Part 2/3 figures and tables |
| `code/drift_data.py` | Part 4 seeded synthetic data generator |
| `code/drift_experiment.py`, `code/report_part4.py` | Part 4 experiment, figure and table |
| `code/collect_results.py` | merges all runs into `results.csv` |
| `hypothesis.md` | Part 3 and Part 4 hypotheses (committed before each experiment) |
