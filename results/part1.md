Exact search on one thread runs at 26 QPS on SIFT and 27 QPS on GloVe when queries are sent one at a time. Batching all 5,000 held-out queries is about 9× faster (239 and 260 QPS). A single query is a matrix-vector product: the whole base (512 MB) is streamed from RAM once per query and only one multiply-add is done per value loaded, so speed is capped by memory bandwidth (≈13 GB/s). A batch becomes a matrix-matrix product (BLAS GEMM) that reuses each cache-resident block of the base across many queries, so it is limited by arithmetic instead (≈61 GFLOP/s, near one core's AVX2 peak).
